## 滤波器对比与适用场景

### 1. 数学本质

所有 FBP 滤波器都是在 **Ram-Lak 滤波器** 基础上加窗：

```
H(f) = |f| × W(f)
        ↑       ↑
     Ram-Lak   窗函数
```

| 滤波器 | 窗函数 W(f) | 公式 |
|--------|------------|------|
| **Ram-Lak** | 1（无窗） | `H(f) = \|f\|` |
| **Shepp-Logan** | sinc | `sin(πfΔ) / (πfΔ)` |
| **Cosine** | cos | `cos(πf/2)` |
| **Hamming** | 0.54+0.46cos | `0.54 + 0.46cos(2πf)` |
| **Hann** | 0.5+0.5cos | `0.5 + 0.5cos(2πf)` |

### 2. 频域特性

```
高频增益 ↑
  1.0 ┼──── Ram-Lak ────── (无滤波, 高频全通)
      │    \
  0.8 ┼     \── Shepp-Logan (轻微抑制高频)
      │      \
  0.6 ┼       \── Cosine (中等抑制)
      │        \
  0.4 ┼         \── Hamming (强抑制)
      │          \
  0.2 ┼           \── Hann (最强抑制)
      │            \
  0.0 ┼────┴────┴────┴────→ 频率
      0    0.25  0.5   0.75  f/fmax
```

### 3. 图像效果对比

| 滤波器 | 分辨率 | 噪声 | RMSE（本次测试） | 视觉效果 |
|--------|--------|------|-----------------|---------|
| **Ram-Lak** | 🥇 **最高** | ❌ 最明显 | **33.62** | 边缘最锐利，但有噪声条纹 |
| **Shepp-Logan** | 🥈 高 | ⚠ 中等 | 38.88 | 边缘锐利，噪声适中 🏆 综合最佳 |
| **Cosine** | 中等 | 较低 | 49.42 | 平滑，噪声少 |
| **Hamming** | 较低 | ✅ 低 | 57.51 | 噪声小，边缘模糊 |
| **Hann** | ❌ 最低 | ✅ **最低** | 59.68 | 最平滑，适合低剂量 |

### 4. 适用场景

#### 🏥 临床 CT 场景

| 场景 | 推荐滤波器 | 原因 |
|------|-----------|------|
| **头部 CT（骨窗）** | **Ram-Lak / Shepp-Logan** | 需要清晰显示骨细节 |
| **头部 CT（脑组织）** | Shepp-Logan / Cosine | 软组织对比度好 |
| **胸部 CT（肺）** | Ram-Lak / Shepp-Logan | 肺纹理细节 |
| **腹部 CT（软组织）** | Cosine / Hamming | 降噪，平滑 |
| **低剂量 CT** | **Hamming / Hann** | 噪声抑制最重要 |
| **儿童 CT** | Hann | 辐射剂量敏感，优先降噪 |

#### 🔬 科研/实验场景

| 场景 | 推荐滤波器 | 原因 |
|------|-----------|------|
| **同步辐射 CT** | Ram-Lak | 信噪比高，追求极限分辨率 |
| **显微 CT** | Shepp-Logan | 平衡分辨率和噪声 |
| **工业 CT（缺陷检测）** | Ram-Lak | 边缘锐利，裂纹清晰 |
| **工业 CT（尺寸测量）** | Shepp-Logan | 精确的边缘定位 |
| **CT 教学演示** | Ram-Lak / 全系列 | 展示滤波效果对比 |


### 6. 选择建议

```python
# 通用选择
filter_name = 'shepp-logan'  # 🏆 综合最佳

# 高分辨率需求（骨、肺、工业缺陷）
filter_name = 'ramp'  # 最锐利

# 低剂量/高噪声数据
filter_name = 'hamming'  # 噪声抑制好

# 最大平滑（儿童、超低剂量）
filter_name = 'hann'  # 最平滑
```

**总结**：没有"最好"的滤波器，只有最适合场景的。**Shepp-Logan** 是大多数场景的稳妥选择，**Ram-Lak** 适合追求分辨率时使用，**Hamming/Hann** 适合噪声较大的数据。
